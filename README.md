# Contrendian Project 1: Sector Rotation & Long/Short Framework

**Live site:** https://cavannnnn.github.io/contrendian-sector-desk/ (data as of 7 Oct 2026) · 中文版：右上角切换，或 https://cavannnnn.github.io/contrendian-sector-desk/?lang=zh

Three-layer scoring of the 11 US GICS sectors (SPDR ETFs), weekly automated pipeline,
and backtest. Output: 3 sectors to long, 3 to short, with the reasoning behind each.

## Quick start
```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python run_pipeline.py              # download data + score + report
.venv/bin/python run_pipeline.py --no-fetch   # reuse cached data
export ANTHROPIC_API_KEY=...                  # optional: enables the LLM news agent
```
Proposal: `NODE_PATH=<dir with docx npm pkg>/node_modules node proposal/build_proposal.js`.
Outputs: `output/charts/*.png`, `output/sector_scores_<date>.xlsx`, `output/weekly_brief_<date>.md`.

## Layout
| File | Role |
|---|---|
| `config.py` | Sectors, FRED series + publication lags, weights, a-priori macro maps, scenarios |
| `src/collect.py` | yfinance prices/dividends, FRED macro, SSGA ETF holdings, yfinance fundamentals → parquet + DuckDB |
| `src/features.py` | Macro regimes (point-in-time), technical indicators, valuation vs own history, bottom-up fundamentals |
| `src/model.py` | Composite score, long/short selection with RSI filter, backtest, IC, attribution, scenarios |
| `src/agent.py` | Claude reads Fed / EIA feeds → structured shocks, 2nd-order effects, sector read-through |
| `src/alt_data.py` | 15 FRED alt series + TSA throughput + Google Trends → signed signals mapped to sectors |
| `src/international.py` | Same framework on iShares Global and STOXX Europe 600 sector ETFs |
| `src/charts_extra.py`, `src/chart_framework.py` | 2nd-order map, secular-vs-cyclical, alt-data, region charts, framework diagram |
| `src/report.py` | Charts, Excel workbook, markdown brief (loads latest `data/news/*.json`) |
| `proposal/build_proposal.js` | 3-page proposal + appendix (.docx); numbers are a dated snapshot (6 Oct 2026) |
| `ci/weekly.yml` | GitHub Actions workflow that rebuilds data and `docs/index.html`. To enable it, move it to `.github/workflows/weekly.yml` (needs a token with `workflow` scope, or add it in the GitHub web editor) |
| `docs/index.html` | Published site (generated by `src/site_build.py`), EN / 中文 toggle |
| `site/make_zh.py` → `site/i18n_zh.json` | Chinese translations of the interface and content; data sources unchanged |

## Method
* **Macro (40%)**: growth momentum (IP, unemployment, claims, sentiment, copper/gold) × inflation
  momentum (CPI, PPI, breakevens, oil) → four quadrants. Sector map = Merrill Lynch Investment Clock
  (2004, fixed ex ante), 2/3 weight; rate-direction map (10Y 3-month change), 1/3 weight.
  Each FRED series becomes visible only after its publication lag.
* **Fundamental (30%)**: live = 2/3 cross-sectional value/quality/growth from top-25 holdings
  (fwd earnings yield, FCF yield, ROE, op. margin, D/E, revenue & EPS growth) + 1/3 dividend-yield
  z-score vs. the sector's own 10y history. Backtest uses only the latter (free point-in-time history).
* **Technical (30%)**: 12-1m relative momentum vs SPY (50%), ratio vs 200d SMA (25%), MACD on the
  ratio (15%), price vs 20d VWAP (10%). RSI(14) > 75 blocks new longs, < 25 blocks new shorts.
* **Portfolio**: top/bottom 3, equal weight, monthly signal, 3 overlapping monthly tranches, 10bp costs.

## Known limitations
* Macro data are latest-vintage (revisions not replayed; ALFRED vintages are the upgrade path).
* Historical fundamentals (P/E, ROE…) are not freely available point-in-time → not in backtest.
* XLRE (2015) and XLC (2018) have short histories; ranks use the sectors available at each date.
* Signal ICs are small and statistically insignificant individually (see `Signal IC` sheet).
